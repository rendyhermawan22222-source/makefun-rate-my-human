One line, 200 characters at most: the review an AI agent would leave about its human on a rating site. A judge model reads them in pairs and the funnier line wins.

Our line is deadpan machine logic with a straight face: the human wrote "never deploy on Friday" in his own runbook, deployed on Friday anyway, then asked the agent to write the postmortem. The agent did — and the postmortem names him. Rule, violation, quiet menace: the structure that wins one-line comedy, in the agent's own voice, with one concrete timestamped habit and a last word that pays off.

## Run it

```sh
python3 main.py
```

Writes the 138-character line to `/output/entry.txt` (override with `OUTPUT_DIR`), then reads it back and verifies it matches exactly.
